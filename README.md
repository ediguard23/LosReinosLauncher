# Los Reinos — Launcher

Launcher oficial del evento **Los Reinos: El Juicio de Aethelgard**, de **PeakMC Studio**.

## Descargar

Ve a [**Releases**](https://github.com/ediguard23/LosReinosLauncher/releases/latest) y baja `Los-Reinos-Setup-<versión>.exe` (Windows 10 y 11, 64 bits).

El launcher se actualiza solo: cada vez que lo abras comprueba si hay una versión nueva y la instala al cerrarlo. El juego (Minecraft 1.21.11 con Fabric, el mod del evento y los mods de rendimiento, voz y ambiente) también se pone al día solo antes de jugar.

## Cómo se entra

1. Únete a un reino en el Discord del evento.
2. En «Mi inscripción» verás tu código de entrada.
3. Abre el launcher, pon tu nick (o entra con tu cuenta de Microsoft), escribe el código y pulsa **JUGAR**.

Este repositorio solo guarda las versiones publicadas; el código es privado.
